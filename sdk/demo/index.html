🔌 SDK Integration Guide
How to embed IntLLM into any web application

Minimal Integration (3 steps)

// Step 1: Import the SDK
import { IntLLM } from './sdk/IntLLM.js';

// Step 2: Initialise with your platform config
const nav = new IntLLM({
  serverUrl:  'ws://localhost:4000',
  platformId: 'crop_doctor',
  lang:       'hi',

  // Step 3: Implement navigation callback
  onNavigate: (route, params) => {
    router.push(route);       // React Router / Next.js / any
  },
  onClarify: (msg, suggestions) => {
    showDialog(msg, suggestions);
  },
  onFallback: (msg) => {
    showToast(msg);
  }
});

// Send audio when user finishes speaking
nav.sendAudio(audioBlob, 'hi');

The platform never needs to know about:

✅ Ollama or any LLM
✅ AI4Bharat IndicConformer
✅ Intent schemas or JSON validation
✅ FSM states or confidence thresholds
✅ The navigation engine internals

It only implements onNavigate(), onClarify(), and onFallback().
